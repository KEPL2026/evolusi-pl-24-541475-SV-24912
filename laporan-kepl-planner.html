1. Tujuan

Membangun aplikasi web Laravel sederhana sebagai implementasi tugas pengembangan perangkat lunak, dengan alur kerja Git berbasis branch, Pull Request, dan pemeriksaan otomatis.

2. Implementasi Aplikasi

  • Halaman utama KEPL Planner dengan tampilan responsif.
  • Form penambahan tugas dengan validasi wajib isi dan batas 120 karakter.
  • Daftar tugas disimpan pada session, sehingga dapat dicoba tanpa konfigurasi database tambahan.
  • Pesan sukses dan error validasi ditampilkan pada halaman yang sama.

4. CI/CD

File .github/workflows/ci.yml berisi dua job:

  • Laravel tests: setup PHP, install Composer, generate key, migrasi SQLite, lalu menjalankan test.
  • Frontend build: setup Node.js, install npm dependencies, lalu menjalankan build Vite.

Hasil lokal: 4 test lulus, 13 assertion lulus, dan Vite production build berhasil.
